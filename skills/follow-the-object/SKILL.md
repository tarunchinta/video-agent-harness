# Skill: follow-the-object

## When to use
Structuring any process explainer. The alternative is a topic tour, which loses
viewers.

## How to apply
1. Choose one concrete thing (a photo's packets, a dollar, a request).
2. Trace its journey start to finish; that journey is the spine.
3. Attach every fact to where the thing is right now — never cut away to
   general background.
4. Use state/medium changes (radio -> light) as act breaks: new visuals, same
   thread.
5. Close the loop symmetrically: pay off exactly what you planted early
   (numbered packets -> reassembled in order).

## Example
Teardown 2026-10-18 (@charles.zhengg, Pacific photo reel): the viewer follows
1,500 packets from phone to cell tower to undersea cable to LA. Routing is
taught as "the routers don't know where this ends" mid-journey, not as a
protocol lecture.

## Anti-pattern
The topic tour: "first, some background on fiber optics..." If a section would
make sense with the object removed, it does not belong.
